# Green-Campus---IW-BI-08-
### Tarea 1.7 - Objetivos de Desarrollo Sostenible (Realizado por: Ander Lizarazu / Rol I4)

#### Implementación Técnica
- **Vistas (views.py):** Integración de `ListView` y `DetailView` genéricas de Django para conectar los modelos de los ODS con el frontend, renderizando el listado y el detalle de iniciativas asociadas.
- **Estructura Semántica HTML5:** Plantillas desarrolladas aplicando estrictamente la teoría de la asignatura. El contenido visible se estructura dentro del `<body>`, utilizando la etiqueta `<main>` para el bloque principal. Dicho bloque se ha subdividido de forma lógica empleando `<article>` y `<section>` para organizar la información de cada ODS.
- **Jerarquía:** Se ha respetado la arquitectura de encabezados, asegurando que el primer título marque la jerarquía del resto del documento.
- **Validación W3C:** El código HTML renderizado ha superado el Nu Html Checker sin errores ni advertencias.
